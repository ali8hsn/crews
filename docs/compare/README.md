# Comparisons

Fair, sourced comparisons with other tools in this space. Each page states what the other
product does well, where Crews genuinely differs, and links the sources it was checked
against, with the date.

Closest first:

- [MCP Agent Mail](mcp-agent-mail.md) — MIT-licensed MCP coordination server with file
  reservations, TTLs and threaded inboxes. The closest comparison here.
- [Agent Orchestration](agent-orchestration.md) — MCP server with resource locks, shared
  memory and a turn-based task queue.
- [Wormhole](wormhole.md) — open MCP server giving agents shared memory and conflict checks.
- [Raft](raft.md) — multi-agent workspace with channels, tasks and hand-off.
- [Buzz](buzz.md) — Block's open workspace where agents are identified members.
- [Entire](entire.md) — agent session capture, checkpoints, and agent-scale git hosting.
- [Cursor Origin](cursor-origin.md) — Git forge built for agent-scale hosting (waitlist).

Corrections are welcome: open an issue. If a page here is out of date or unfair to a
competitor, that is a bug.

## Not covered, and why

A product called **Befall** was on the list to compare against, described as an MCP server
with enforced path locks. Repeated searches on 7 September 2026 found no product, repository,
package or domain by that name, so no page was written. Writing a comparison against a product
that cannot be located would be inventing one. If the name is right, send a link and the page
will be written; the description matches [MCP Agent Mail](mcp-agent-mail.md), whose optional
pre-commit hook does enforce reservations, so that may be the tool that was meant.
